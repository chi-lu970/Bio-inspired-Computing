PyVRP 前後端實作需求規格書
一、專案背景與目標
本專案旨在為現有的 PyVRP（Vehicle Routing Problem）求解專案新增一套前端視覺化操作介面，並撰寫對應的 Python 後端 API，使使用者能夠透過網頁介面輸入路徑規劃所需參數，並取得最佳化路線結果與視覺化地圖。

二、前端頁面需求
2.1 輸入表單
前端頁面須提供以下欄位供使用者填寫：
（1）地點分布資訊（WGS84 經緯度）

倉庫位置：一個倉庫，填寫經緯度（暫限單一倉庫）
店面位置：多個店面，每筆填寫店面名稱與其經緯度；支援動態新增／刪除店面

（2）時間窗口（Time Window）

倉庫的開放補貨時間窗口（起始時間與結束時間，自由填寫）
各店面各自的可接受補貨時間窗口（起始時間與結束時間，自由填寫）

（3）需求量

各店面的貨物需求量（單位：重量 kg 或件數，可擇一或同時填寫）

（4）車隊配置（支援混合車隊）

車輛總數
各車輛的載重上限（容量），支援不同車型（即不同車輛可設定不同容量）

2.2 操作流程

使用者填寫完畢後，點擊「開始計算」按鈕
後端執行 PyVRP 最佳化求解
前端接收結果並渲染路線圖與詳細資訊


三、後端處理需求
3.1 座標轉換
後端接收前端傳入的 WGS84 經緯度後，需使用 Python 工具（如 pyproj）將其轉換為 UTM（Universal Transverse Mercator）座標，供 PyVRP 進行距離計算。
3.2 VRP 求解
將轉換後的座標、時間窗口、需求量、車隊資訊傳入 PyVRP 模組，執行求解並回傳最佳化路線結果。
3.3 回傳資料格式
後端需回傳以下資料供前端渲染：

各車輛的行駛路線順序（含倉庫出發點）
各路段的距離（公里或公尺）
各車輛抵達各店面的預估時間
各車輛的總行駛距離與總載重


四、結果視覺化需求
4.1 路線地圖

使用支援互動操作的地圖套件（建議：Leaflet.js 或 Folium）呈現
地圖需佔據網頁較大顯示區塊（建議 70% 視窗高度以上）
支援拖動、縮放操作
標示倉庫位置（特殊圖示區分）
標示各店面位置（含店面名稱標籤）
以不同顏色的路線繪製各車輛的行駛軌跡

4.2 路線詳細資訊
地圖旁或下方顯示每台車輛的行程明細，包含：

行駛順序（倉庫 → 店面 A → 店面 B → …）
各路段距離
抵達各店面的時間
該車輛總行駛距離與總載重
